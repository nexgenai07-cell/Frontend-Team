# 📚 Digital Library App

A React-based Digital Library application built to practice core frontend concepts like routing, API integration, state management, and reusable components.

---

## 👩‍💻 Project Info

- **Created By:** Urba Zahid  
- **Date:** 22 May 2026  
- **Project Type:** React Intermediate (Books Library App)

---

## 🚀 Features

- Multi-page React app using React Router DOM  
- Home, Books, and Contact pages  
- Fetch data from public API  
- Dynamic book listing using `.map()`  
- Add / Remove favorite books (toggle system)  
- Favorite counter  
- Search books by name  
- Loading and error handling  
- Reusable components (BooksCard)  
- Clean and responsive UI
