# 💳 Payment Flow Simulation App

A React-based e-commerce checkout simulation app built to practice frontend concepts like routing, form validation, state management, and payment flow logic.

---

## 👩‍💻 Project Info

- **Created By:** Urba Zahid  
- **Date:** 04 June 2026  
- **Project Type:** React Intermediate (Checkout & Payment Simulation App)

---

## 🚀 Features

- Cart → Checkout → Success / Failed flow  
- React Router DOM navigation  
- Payment method selection (Card, UPI, Wallet)  
- Form validation (name, email, address, card, CVV, UPI ID)  
- Stripe-style Payment Intent generator  
- Order creation system  
- Toast notifications  
- Responsive UI  

---

## 🧠 Payment Flow

- Payment Intent ID generated using random function  
- Fake delay added using setTimeout  
- Card ending in `0000` simulates failure  
- Data passed using React Router `state`  

Flow:

Cart → Checkout → Validate → Process Payment → Success / Failed
