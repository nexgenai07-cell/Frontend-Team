# 🌍 Travel Places UI (React + Tailwind)

## 📌 Description

A simple React-based Travel UI that displays dynamic places using components, state management, and Tailwind CSS.

---

## ⚙️ Tech Stack

- React (Vite)
- Tailwind CSS
- JavaScript (ES6)

---

## ✨ Features

- Dynamic place cards using `.map()`
- Like counter using `useState`
- Show / Hide details toggle
- Event handling (buttons)
- Responsive UI with Tailwind

---

## 📦 Setup

```bash
npm install
npm run dev
```
