# 🎓 Student Portal App

A simple React-based Student Portal application built for learning core frontend concepts like routing, API integration, and state management.

---

## 📌 Project Info

- **Created By:** Urba Zahid  
- **Date:** 17 May 2026  
- **Task:** Day 6 React Intermediate  

---

## 🚀 Features

- Multi-page React app using React Router DOM  
- Home, About, and Students pages  
- Fetch data from public API  
- Dynamic student table using `.map()`  
- Loading state handling  
- Error handling for API failures  
- Reusable components (Navbar & Footer)  

---

## 🌐 API Used

https://jsonplaceholder.typicode.com/users

## 📦 Dependencies

Install required packages:

```bash
npm install
```
