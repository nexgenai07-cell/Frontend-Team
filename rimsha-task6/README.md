# 🎓 EduTrack - Student Portal App

EduTrack is a modern and responsive Student Management System built using React and Tailwind CSS.
It provides a clean interface to view and manage student records in a structured format.
---

## 🚀 Features

- Multi-page React application
- Clean and modern UI design
- Student records displayed in card format
- Dynamic data rendering using API
- Loading state while fetching data
- Error handling for failed requests
- Reusable components (Navbar, Footer, Cards)
- Responsive design for all devices
- Smooth navigation between pages

---

## 🛠️ Tech Stack

- React JS
- React Router DOM
- Tailwind CSS
- React Icons
- JavaScript (ES6+)

## 🌐 API Used

This project uses a free public API for student data:

```
https://jsonplaceholder.typicode.com/users
```

It provides sample user data including:

- Name
- Email
- Address
- Company

## ⚙️ Installation & Setup

### 1. Clone the repository

```bash
git clone https://github.com/your-username/edutrack.git
```

### 2. Move to project folder

```bash
cd edutrack
```

### 3. Install dependencies

```bash
npm install
```

### 4. Install required packages

```bash
npm install react-router-dom react-icons
```

### 5. Run the project

```bash
npm run dev
```
